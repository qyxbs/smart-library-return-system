# 部署指南

## 硬件接线

### RK3566 外设
| 接口 | 连接 | 说明 |
|------|------|------|
| MIPI CSI dphy1 | OV5695 摄像头 | I2C 地址 0x36, rkisp 驱动 |
| AUDIO 口 | 驻极体麦克风 | RK809 Codec, MIC1P 单端 |
| HDMI | LT6911UXC 触摸屏 | 1024×600@60Hz, TMDS 51.25MHz |
| USB 2.0 | 有源 Hub | **必须外接 5V 供电** |
| USB Hub → | 88x2bu WiFi 网卡 | 802.11bgn 2.4GHz |
| USB Hub → | 触屏触控信号 | OpenWare Multi-Touch-V5000 |
| USB Hub → | USB-TTL 调试串口 | 可选 |
| UART4 | 无线串口模块 → STM32 | 9600bps, GPIO3_B1/B2 |
| UART5 | 无线串口模块 → STM32 | 38400bps, GPIO3_C3/C2 |
| UART9 | EM20L 打印机 | 115200bps, GPIO4_C6/C5, 3线制 clocal |

### STM32 接线
- 主控 STM32F407 通过无线串口模块接收 RK3566 指令
- 通过 CC2530 Zigbee 模块广播至三个 STM32F103 子控制器
- 子控制器通过 RS485 总线控制各步进电机

### K230 接线
- K230 #1: GC2093 摄像头 (MIPI CSI), 部署于整书区底部
- K230 #2: 全局快门摄像头 + UART2 (GPIO11/12, 38400bps) 连接 STM32 主控

## 供电

```
220V AC → 200W 变压器 → 12V DC
  → 各电路板隔离电源
  → RK3566 (USB-C 5V 独立供电)
  → K230 ×2 (USB-C 5V 独立供电)
  → USB 有源 Hub (5V 外接供电必须接入)
```

## 软件部署（RK3566 主控）

主控侧是 C++ 工程（`1-RK3566-主控/cpp/`），语音、扫码、音频采集为独立 Python 服务。

### 1. 交叉编译

```bash
cd 1-RK3566-主控/cpp

# 从板端提取交叉编译所需的 SQLite 库（板子在线时执行一次）
BOARD=root@<BOARD_IP> bash scripts/fetch_sysroot.sh

# 交叉编译
cmake -B build-arm64 -DCMAKE_TOOLCHAIN_FILE=toolchain-aarch64.cmake -DCMAKE_BUILD_TYPE=Release .
cmake --build build-arm64 -j
```

产物：`build-arm64/book_server`（HTTP :9777）与 `build-arm64/k230_bridge`（:9998 / :9997 / :9999 / :9995）。

> sysroot 也可用 `-DBOOK_SYSROOT=/path/to/sysroot` 指定；其中需包含 `lib/aarch64-linux-gnu/libsqlite3.so`。
> 本机调试可直接 `cmake -B build . && cmake --build build -j`（x86，使用系统 SQLite）。

### 2. 部署二进制与静态页面

```bash
BOARD=root@<BOARD_IP> bash 1-RK3566-主控/deploy-scripts/deploy_cpp.sh
```

脚本会完成：编译 → 拷贝 `book_server` / `k230_bridge` / `static/` 到 `/userdata/book_app/` → 安装 `S99book` / `S99bridge` → 重启服务。

也可手动部署：

```bash
ssh root@<BOARD_IP> "mkdir -p /userdata/book_app"
scp build-arm64/book_server build-arm64/k230_bridge root@<BOARD_IP>:/userdata/book_app/
scp -r static root@<BOARD_IP>:/userdata/book_app/
scp init-scripts/S99book init-scripts/S99bridge root@<BOARD_IP>:/etc/init.d/
ssh root@<BOARD_IP> "chmod +x /etc/init.d/S99book /etc/init.d/S99bridge"
```

### 3. 开机自启

仓库内的 init 脚本：

| 脚本 | 作用 |
|---|---|
| `S98wifi` | WiFi STA 连接（凭据从 `/etc/wifi.conf` 读取） |
| `S99book` | 主控 HTTP 服务（book_server） |
| `S99bridge` | K230 桥接（k230_bridge） |
| `S99a-voice` | 语音服务（voice_web_app.py，:8890） |
| `S99sysmon` | 系统监视 |

系统镜像自带的 `S50sshd` / `S50weston` / `S51kiosk`（HDMI kiosk）与 `S99qrscanner` 不在本仓库，按需在镜像层面配置。

### 4. 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `BOOK_DB_PATH` | `/userdata/book_app/book.db` | SQLite 数据库路径 |
| `BOOK_STATIC_DIR` | `/userdata/book_app/static` | 管理页面静态目录 |
| `BOOK_HTTP_PORT` | `9777` | HTTP 端口 |
| `BOOK_LOG_PATH` | `/var/log/book_server.log` | 日志文件 |
| `ADMIN_PIN` | 未设置时随机生成并打印到日志 | 管理员 PIN，**部署时必须固定** |
| `BOOK_TOKEN_SECRET` | 内置默认值 | 登录 token 签名密钥，**部署时必须覆盖** |
| `K2302_HOST` | `127.0.0.1` | K230 #2 地址（局域网独立设备时填其 IP） |
| `VOICE_SERVICE_URL` | `http://127.0.0.1:8890` | 语音服务地址（C++ 代理使用） |
| `VOICE_TLS` | `0` | 语音服务是否启用 HTTPS（默认 HTTP，供本机代理直连） |

### 5. 语音服务资产

语音服务（`voice_web_app.py`）需要以下文件与依赖，因体积原因不入库：

- `requirements.txt`（本目录）：`pip install -r requirements.txt`
- 模型：`/userdata/voice_app/models/`（SenseVoice ONNX、声纹模型）
- 书库：`/userdata/voice_app/book_db.json`（书名索引，可替换为自有数据）
- 证书：仅 `VOICE_TLS=1` 时需要 `voice_cert.pem` / `voice_key.pem`

### 6. 小程序与 HDMI 面板

- 小程序：修改 `4-微信小程序/config/api.js` 的 `baseAPI` 为板子地址（`utils/request.js` 统一从这里取值），微信开发者工具导入后编译。
- HDMI 面板：浏览器打开 `http://<BOARD_IP>:9777/screen`，或由系统镜像的 kiosk 脚本自动打开。

## K230 RT-Smart
- 使用嘉楠 SDK 交叉编译应用程序
- 通过 microSD 卡烧录固件
- WiFi STA 自动接入，DHCP 获取 IP

## STM32 RT-Thread
- 使用 RT-Thread Studio 或 env 工具编译
- 通过 SWD (ST-Link) 烧录固件
- CC2530 Zigbee 模块即插即用（无线串口透传）

```bash
# K230 状态
curl http://<BOARD_IP>:9777/api/k230/status

```

## 故障排查

| 现象 | 排查方向 |
|---|---|
| `book_server` 启动即退出 | 看 `/var/log/book_server.log`：数据库路径、端口占用、静态目录 |
| 登录返回 400 | 确认前端发送 `code` 或 `openid`；看服务日志 |
| 语音接口 404 | 确认 `VOICE_SERVICE_URL` 与语音服务实际端口/协议一致 |
| 语音 500 | 检查 `book_db.json`、模型文件与 `requirements.txt` 依赖 |
| K230 桥接异常 | 检查 `K2302_HOST`、K230 固件协议（`BOOK:`/`SHELVE`/`FETCH`）与网络连通 |
| 交叉编译报错找不到 SQLite | 运行 `scripts/fetch_sysroot.sh` 或指定 `-DBOOK_SYSROOT` |
