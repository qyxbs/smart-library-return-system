# 部署指南

## 硬件接线

### RK3566 外设
| 接口 | 连接 | 说明 |
|------|------|------|
| MIPI CSI dphy1 | OV5695 摄像头 | I2C 地址 0x36, rkisp 驱动 |
| AUDIO 口 | 驻极体麦克风 | RK809 Codec, MIC1P 单端 |
| HDMI | LT6911UXC 触摸屏 | 1024×600@60Hz, TMDS 51.25MHz |
| USB 2.0 | 有源 Hub | **必须外接 5V 供电** |
| USB Hub → | 88x2bu WiFi 网卡 | 802.11bgn 2.4GHz |
| USB Hub → | 触屏触控信号 | OpenWare Multi-Touch-V5000 |
| USB Hub → | USB-TTL 调试串口 | 可选 |
| UART4 | 无线串口模块 → STM32 | 9600bps, GPIO3_B1/B2 |
| UART5 | 无线串口模块 → STM32 | 38400bps, GPIO3_C3/C2 |
| UART9 | EM20L 打印机 | 115200bps, GPIO4_C6/C5, 3线制 clocal |

### STM32 接线
- 主控 STM32F407 通过无线串口模块接收 RK3566 指令
- 通过 CC2530 Zigbee 模块广播至三个 STM32F103 子控制器
- 子控制器通过 RS485 总线控制各步进电机

### K230 接线
- K230 #1: GC2093 摄像头 (MIPI CSI), 部署于整书区底部
- K230 #2: 全局快门摄像头 + UART2 (GPIO11/12, 38400bps) 连接 STM32 主控

## 供电

```
220V AC → 200W 变压器 → 12V DC
  → 各电路板隔离电源
  → RK3566 (USB-C 5V 独立供电)
  → K230 ×2 (USB-C 5V 独立供电)
  → USB 有源 Hub (5V 外接供电必须接入)
```

## 软件部署

### RK3566 系统初始化
```bash
# 1. 烧录系统镜像（包含内核 + rootfs）
# 2. 连接 WiFi
# 3. 安装 Python 依赖
pip install flask opencv-python pyserial sherpa-onnx pypinyin

# 4. 部署应用代码
scp -r book_app/* root@<rk3566_ip>:/userdata/book_app/
scp k230_bridge_v2.py root@<rk3566_ip>:/userdata/book_app/
scp voice_web_app.py root@<rk3566_ip>:/userdata/voice_app/

# 5. 部署开机自启脚本
scp init-scripts/* root@<rk3566_ip>:/etc/init.d/
chmod +x /etc/init.d/S*

# 6. 部署系统监视
scp sysmon.sh root@<rk3566_ip>:/usr/bin/
```

### 启动顺序
```
S50sshd     → SSH 服务 (dropbear)
S50weston   → Weston Wayland 合成器 (HDMI)
S98wifi     → WiFi STA 连接
S99book     → Flask API :9777
S99a-voice  → 语音 AI 服务 :8890
S99k230     → K230 Bridge :9998/:9999
S99qrscanner → OV5695 扫码服务
S99kiosk    → Chromium kiosk (依赖 Weston + Flask)
S99b-tailscale → Tailscale Funnel + SSH
S99sysmon   → 系统监视
```

### Tailscale Funnel (公网 HTTPS)
```bash
# ARM64 二进制 v1.98.8
tailscaled --tun=userspace-networking &
tailscale up                    # 首次认证
tailscale funnel --bg 9777      # 暴露 Flask 到公网
# 固定域名: https://YOUR_SERVER_DOMAIN (使用 Tailscale Funnel 或 ngrok)
```

### K230 RT-Smart
- 使用嘉楠 SDK 交叉编译应用程序
- 通过 microSD 卡烧录固件
- WiFi STA 自动接入，DHCP 获取 IP

### STM32 RT-Thread
- 使用 RT-Thread Studio 或 env 工具编译
- 通过 SWD (ST-Link) 烧录固件
- CC2530 Zigbee 模块即插即用（无线串口透传）
