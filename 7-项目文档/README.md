## 系统架构速览

```
┌──────────────┐     TCP :9998      ┌──────────────┐     TCP :9999      ┌──────────────┐
│  K230 #1     │ ──── QR 扫码 ────▶ │   RK3566     │ ──── 坐标指令 ──▶ │  K230 #2     │
│  RT-Smart    │                    │   Linux      │                    │  RT-Smart    │
└──────────────┘                    │   Flask API  │                    └──────┬───────┘
                                    │   SQLite     │                    UART2 │
                                    └──────┬───────┘                    STM32 │
                                    UART4/5│                                  │
                                           ▼                                  ▼
                                   ┌──────────────┐    Zigbee     ┌──────────────────┐
                                   │ STM32F407    │ ────广播────▶ │ STM32F103 ×3     │
                                   │ RT-Thread    │               │ RT-Thread        │
                                   │ 主控         │               │ 推书/机械爪/三轴   │
                                   └──────────────┘               └──────────────────┘
```

**三芯异构**：RK3566 (Linux, AI 推理) + K230 ×2 (RT-Smart, 视觉感知) + STM32 ×4 (RT-Thread, 实时控制)

**双引擎 AI**：有网 → DeepSeek API；断网 → 本地 Qwen3-0.6B LoRA（<300ms 自动切换）

**分布式控制**：Zigbee 广播 + RS485 总线，7 路步进电机，硬实时毫秒级响应
