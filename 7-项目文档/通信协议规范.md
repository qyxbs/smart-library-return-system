# 通信协议规范

## 概述

系统内各设备间采用文本行协议（换行符 `\n` 分隔），关键数据帧附加 CRC-4/ITU 校验。文本行格式便于手工逐条调试验证。

## CRC4 校验

- **算法**：CRC-4/ITU
- **多项式**：poly=0x3
- **初始值**：init=0x0
- **处理范围**：仅每字节低 4 位
- **测试向量**：
  - CRC4("BOOK:12345") = 0x9 → "0009"
  - CRC4("BOOK:1") = 0xA → "000A"
  - CRC4("STOP:RETURN") = 0xB → "000B"
  - CRC4("HELLO") = 0xC → "000C"

## K230 #1 ↔ RK3566 (TCP :9998)

K230 #1 作为 TCP 客户端发起长连接。

### K230 #1 → RK3566
```
READY\n                        启动握手，通知 RK3566 已就绪
BOOK:<book_id>:<CRC4>\n        扫到书标 QR 码，上报书本 ID
STOP:RETURN:<CRC4>\n           扫到停止码，通知循环结束
```

### RK3566 → K230 #1 (同一连接)
```
WAKE\n                         唤醒扫码（收到后启动摄像头）
SLEEP\n                        休眠（收到后关闭摄像头）
ACK\n                          确认（WAKE/SLEEP/BOOK/STOP 的应答）
NAK:<reason>\n                 拒绝（book_id 无效、CRC 不匹配等）
```

### 管理指令（通过 TCP 127.0.0.1:9998 本地回环）
```
ADMIN:WAKE\n                   管理员远程唤醒扫码
ADMIN:SLEEP\n                  管理员远程休眠
```
管理指令即时处理即断开，不替换 K230 #1 的数据链路。

## RK3566 → K230 #2 (TCP :9999)

RK3566 作为 TCP 客户端发起长连接。

### RK3566 → K230 #2
```
SHELVE,<y>,<x>\n               上架指令，y=层(1-2), x=列(0-8)
FETCH,<y>,<x>\n                取书指令
INIT\n                         机械归位
START_RETURN\n                 启动还书推书流程
PUSH_NEXT\n                    推下一本书
```

### K230 #2 → RK3566 (TCP :9997 短连接)
```
TRIGGER\n                      限位开关触发（书已推到扫码位）
DONE\n                         爪子上架完成
FETCH_DONE\n                   取书完成
ERROR:<msg>\n                  异常报告
```

## RK3566 → STM32 (UART 无线串口)

### UART4 (9600bps) — 坐标指令
```
FA + 1字节坐标                 放书: FA\x15 (坐标15)
FB + 1字节坐标                 取书: FB\x17 (坐标17)
```
坐标范围: 11-18 (一层), 21-28 (二层)

### UART5 (38400bps) — 控制指令
```
FD 88 88 FD                   启动机械爪流程
AA BB CC DD                   结束/复位
```

## 书标 QR 码格式

```
BOOK:<book_instance_id>:<CRC4>
例: BOOK:12345:0009
```

停止码:
```
STOP:RETURN:<CRC4>
例: STOP:RETURN:000B
```

## 坐标映射

```
一层: 教辅(11-14) + 文学(15-18)
二层: 科技(21-24) + 其他(25-28)

coord_y = YX (两位十进制): Y=coord_y//10, X=coord_y%10
例: 15 → Y=1, X=5; 23 → Y=2, X=3
```
