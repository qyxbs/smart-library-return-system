# 系统架构说明

## 三芯异构边端协同

系统采用 RK3566 (Cortex-A55×4) + K230×2 (RISC-V 双核) + STM32×4 (Cortex-M4/M3) 三芯异构架构，按任务特征分配最适合的操作系统：

| 芯片 | OS | 定位 | 核心任务 |
|------|-----|------|---------|
| RK3566 | Linux 6.1 | 边缘计算 + 业务调度 | Flask API、SQLite、AI 双引擎、Bridge 中间件 |
| K230 #1 | RT-Smart | 视觉感知 (扫码) | QR 解码 + CRC4 校验 + vote 3/3 |
| K230 #2 | RT-Smart | 视觉感知 (导航) | AprilTag PnP 位姿估计 + UART2 桥接 |
| STM32F407 | RT-Thread 标准版 | 主控协调 | Zigbee 广播 + RS485 管理 |
| STM32F103 ×3 | RT-Thread 标准版 | 实时执行 | 步进电机控制 + 传感器采集 + 中断响应 |

## 软件分层架构

```
┌─────────────────────────────────────────┐
│  表示层: HDMI 触屏 + 微信小程序            │  软实时 (秒级)
├─────────────────────────────────────────┤
│  业务逻辑层: Flask API + SQLite + 任务队列 │
├─────────────────────────────────────────┤
│  中间件层: K230 Bridge + 扫码 + 语音 AI    │
├──────────────┬──────────────┬───────────┤
│  OS: Linux   │ OS: RT-Smart │ OS: RT-Thread │
│  RK3566      │ K230 ×2      │ STM32 ×4     │
├──────────────┼──────────────┼───────────┤
│  硬件驱动层    │  摄像头驱动    │  电机驱动     │  硬实时 (毫秒级)
└──────────────┴──────────────┴───────────┘
```

## 通信架构

```
K230 #1 ──TCP :9998 (长连接)──▶ RK3566 ◀──TCP :9999 (长连接)── K230 #2
                                    │
                              UART (无线串口)
                                    │
                                    ▼
                              STM32F407 ──Zigbee──▶ STM32F103 ×3
                                                   (推书 / 机械爪 / 三轴)
```

所有设备连接同一 2.4GHz WiFi 局域网，关键数据帧附加 CRC-4/ITU 校验。

## 数据流

### 借书
```
小程序生成QR → OV5695扫码 → Flask API → DB变更 → 任务队列入队
→ UART发坐标 → STM32广播Zigbee → 机械爪取书 → 用户取书
```

### 还书
```
小程序生成QR → OV5695扫码 → 创建还书任务
→ STM32推书 → 限位触发 → K230#1扫码 → Bridge状态机验证
→ K230#2导航上架 → 机械爪归位 → 循环或结束
```

### 语音录入
```
麦克风采集 → 声纹验证 → ASR语音识别 → LLM书名提取+分类
→ 三级容错纠正 → DB注册 → 标签打印
```
