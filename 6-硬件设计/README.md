## 电路设计 (`电路/`)

电路设计文件（原理图、PCB、接线图）正在整理中。

### 供电架构

```
220V AC → 200W 变压器 → 12V DC
  → 各电路板隔离电源
  → RK3566 (USB-C 5V)
  → K230 ×2 (USB-C 5V)
  → USB 有源 Hub (外接 5V 供电)
```

### 关键注意事项

- USB 有源 Hub 必须外接 5V 供电，否则 WiFi 高负载时电压跌落会导致系统复位
- 无线串口模块用于 RK3566 ↔ STM32 通信，替代有线连接
- CC2530 Zigbee 模块实现 STM32 主控与子控间的无线广播
