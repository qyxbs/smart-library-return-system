# 智能图书自动归位系统

基于 RT-Thread 生态的边端协同智能图书管理系统，实现图书的自动识别、分类、定位与归位。

## 系统概述

本系统采用**三芯异构**架构，按任务特征将计算分配到最适合的硬件平台：

- **RK3566** (Cortex-A55×4, Linux) — 边缘计算中枢，负责业务调度、AI 推理、数据库管理
- **K230 ×2** (RISC-V 双核, RT-Smart) — 视觉感知端，分别负责 QR 扫码识别与 AprilTag 导航定位
- **STM32 ×4** (Cortex-M4/M3, RT-Thread) — 实时控制端，分布式管理 7 路步进电机与多路传感器

用户通过**微信小程序**浏览书架、扫码借还；管理员通过**HDMI 触屏**或**语音指令**完成图书录入与上下架操作。语音识别在本地完成（SenseVoice），书名提取与分类调用云端 DeepSeek API；离线时降级为关键词规则。

## 快速开始

### 硬件要求

| 组件 | 数量 | 说明 |
|------|------|------|
| RK3566 开发板 | 1 | 主控制器，需 MIPI CSI + HDMI + USB |
| K230 开发板 | 2 | 视觉感知，需 MIPI CSI 摄像头 |
| STM32F407VET6 | 1 | 实时控制主控 |
| STM32F103C8T6 | 3 | 子控制器（推书/机械爪/三轴运动） |
| OV5695 摄像头 | 1 | 接 RK3566，扫码触发 |
| EM20L 热敏打印机 | 1 | 标签打印 |
| 步进电机 | 7 | 推书×1 + 机械爪×3 + 三轴×3 |
| CC2530 Zigbee 模块 | 4 | 分布式控制通信 |

### 软件部署

详见 `7-项目文档/部署指南.md`。核心步骤：

1. RK3566 烧录 Linux 镜像，交叉编译部署 C++ 主控（book_server / k230_bridge），并按需部署语音、扫码服务
2. K230 烧录 RT-Smart 固件，部署视觉应用
3. STM32 烧录 RT-Thread 固件
4. 所有设备连接同一 WiFi 热点
5. 微信小程序配置后端域名

### 通信架构

所有设备接入同一局域网，TCP 文本行协议 + CRC-4/ITU 校验保证数据完整性。详见 `7-项目文档/通信协议规范.md`。
